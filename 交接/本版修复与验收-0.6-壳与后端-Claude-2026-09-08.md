## 定下的路径（对照执行）

| 决定 | 做法 |
|---|---|
| 全换 Qwen3，只做 4B 和 8B | 4B 档两个模型 `qwen3:4b-instruct-2507-q4_K_M`（作答）+ `qwen3:4b-thinking-2507-q4_K_M`（深度思考）；8B 档没有拆开的 2507 版，用混合型 `qwen3:8b` 加 think 开关。按内存自动选档（≥12GB → 8B）。Ollama 库里更新的 Qwen3.5（4B/9B）作为自定义项留给你实测，没有默认押它。 |
| 壳的能力：装好后可通过 API / CLI / claude -p / 本地模型调用并显示状态 | 新增 `lulu/backends.py`：四种后端一个接口，`config.json` 一个字段切换；钥匙单独存 `data/secrets.json`（0600），不进 config、不进安装包。状态接口 `GET /api/backend`，切换 `POST /api/backend`，体检 `POST /api/backend/probe`，试一句 `POST /api/backend/test`，存钥匙 `POST /api/backend/secret`。 |
| 主推 7B（=8B 档），重在总结、提醒、翻译、提取、闲聊，搜索能加就加 | 新增翻译技能；总结/提取/提醒/闲聊/记录/记忆问答保留并收紧路由；搜索改成可插拔提供方（博查 / Tavily / Brave 官方 API + 无钥匙抓取兜底），用户填哪家钥匙走哪家。 |
| 推理默认关闭，UI 可开启 | `think` 是每次调用的参数，只作用于生成类槽位（闲聊、总结、写文档、翻译、联网问答的最后作答）；分类、抽取、核对永远不思考。工作窗口"模型"页有"深度思考"开关，随时可切，不用重启。思考文本不进答复、不进记录正文。 |

## 结构

```
lulu/backends.py    后端配置、档位、钥匙、构建 provider、体检、命令行工具
lulu/searchapi.py   搜索提供方：bocha / tavily / brave / engines（无钥匙抓取）
lulu/models.py      OllamaProvider（两模型或混合 + think）、OpenAICompatibleProvider（enable_thinking / 推理模型名）、
                    CommandProvider（任意命令行）、ClaudeCliProvider（claude -p --output-format json）
lulu/skills.py      route_rules() 规则优先路由；translate 技能；generate 的材料门槛；query 的"问句即查询"与无资料回退
lulu/loop.py        Agent.set_provider / set_think；classify() 规则命中时不调模型；think 传入生成槽位
lulu/research.py    research(searcher=…)：提供方给的答案也当一页可引用原文
lulu/server.py      /api/backend 系列；/api/desktop 带 backend 状态；版本 0.6-preview
desktop/src/pet.gd  新增"模型"页；状态栏显示后端·模型·深度思考；任务进行中提示"深度思考中"
```

### 路由：规则优先，模型兜底

`skills.route_rules()` 先看决定性句式，命中就直接定技能、**不调分类模型**（省一次 7B 调用，也少一次判错）。顺序：提醒 → 记忆问答 → 记录 → 转换 → 翻译 → 总结（总结动词在生成动词之前且有材料对象）→ 生成（文件契约）→ 本地查找 → 关于 Lulu 自己的话 → 查询 → 任何问句（吗/呢/？/什么/怎么/听说/是真的吗…）→ 短句闲聊。一句话里两件事（并且/然后/顺便 + 两个技能词）交给分类器和通用循环。

"xx是真的吗""听说xxx"按你的意思算查询：有搜索钥匙就联网并按核对过的原文作答；没资料且不是实时类问题，就用模型自己的知识回答并在末尾标注"没有联网核对到资料"；实时类（今天/最新 + 价格/新闻/天气）资料不足仍然暂停提问，不编数字。

### 翻译

`translate`：目标语言从句子里取（翻译成英文 / 英文怎么说 / 译为日文），取不到就按原文判向（中文→英文，其他→中文）；原文来自引号、"翻译：" 之后、指定文件或上一条回答；长文按段切块逐段译。验收：数字必须原样出现、长度比例在 0.15–6 之间，不过重译一次再标注。指定文件时写 `译文-<原名>.<md|txt|docx>`，否则直接回。

### 深度思考

| 后端 | 关 | 开 |
|---|---|---|
| Ollama 4B 档 | 调 instruct 模型，不传 think | 调 thinking 模型，`think: true`，`num_predict` 多留 1500 |
| Ollama 8B 档（混合） | `think: false` | `think: true` |
| API（通义等） | 不传 | `enable_thinking: true`（可在 config 里改参数名；DeepSeek 预设改为切到 `deepseek-reasoner`） |
| claude -p / 其他命令行 | 不支持，开关无效 | 同左 |

## 0.6.1 补丁（2026-09-08，按第一次真机会话修）

真机会话里的三处"傻"都不是模型：

1. **"本机服务连接中断，正在重连…"**（问"我听说openai越狱了？"时）——`websearch.check_url` 在异步抓取里用了同步的 `socket.getaddrinfo`，DNS 一慢整个事件循环卡住，启动器连续三次健康检查失败就把 Agent 重启了。这也是 0.5 日志里"Restarting agent"×3 的来源。改为线程内解析、6 秒封顶，网页解码与去标签也移到线程。
2. **"帮我把上一份文件翻译成英文" → "The previous document"**——翻译技能没有解析"上一份文件"这类指代，把这四个字当原文译了。新增 `referenced_file()`：上一份/上个/刚才那个/最新的文件 → 本会话最近产物，否则工作文件夹最新文件；翻译、总结、转换共用。
3. **"我是说上一份文件的内容，" → "什么时候提醒你？"**——这句没有决定性句式，交给了分类模型，8B 判成 reminder，程序又信了它。两层修：分类结果里 reminder/memory 必须有用户自己的提醒/记忆词才作数；以"我是说/我的意思是/不对/不是"开头的话视为对上一个任务的更正，沿用上一个技能、把两句合并（事件 `follow_up`），不再重新分类。

回归 131 项通过；四个失败场景各有一条测试钉住。Ollama 调用现在记录 `load_seconds / total_seconds / thinking_chars`，用来查"深度思考 46 秒里只算了 4 秒"的去向。

## 0.7 标签行（2026-09-08，按"选项卡加闲聊"的方案）

**思路**：所有"傻"都出在程序猜用户想干什么；让用户点一下标签再打字，猜测这一层整个没了，7B 只做变形。输入框上方一排 11 个标签（翻译 · 总结 · 改写润色 · 问文件 · 提取成表 · 按要点写 · 转格式 · 记一下 · 提醒 · 查一下 · 聊聊天），点了标签就锁定技能、跳过路由和分类模型；每个标签带自己的小选项（翻成 / 长度 / 怎么改 / 写什么 / 结果格式 / 去哪里找 / 记到 / 表格列名）；"选文件…"从工作文件夹多选，选中的文件直接进槽位，不再问"哪个文件"；不点标签直接打字的老路保留。

**后端**：`POST /api/chat` 多收 `skill / files / options`，写进任务的 `intent.forced`；`TaskRun.classify()` 看到 forced 就不调分类模型；`/api/state` 多给 `skills` 与 `skill_options`；`/api/desktop` 多给 `last_artifact`（"刚生成的文件"）。新增三条技能：

| 技能 | 程序保证 |
|---|---|
| `rewrite` 改写润色 | 九种"怎么改"各有明确指令；数字必须原样出现；"只改错别字和标点"时长度只允许 ±20%；不过重做一次再标注 |
| `ask_file` 问文件 | 答案必须附一段一字不差的原文；引用核对不过或数字无来源就标"请对照原文确认"；文件里没有的答"没有提到" |
| `extract` 提取成表 | 列名来自选项或句子；每个格子的值必须在原文里出现，否则留空并计数；结果直接显示或写 Excel/CSV |

规则路由也认这三类句式（改写/润色/正式一点…；xx 里的 A、B 提取成表；文件里…是多少）。

**文案**：全部按润色稿替换（标签、提示语、程序问句、完成回复、状态栏、各页说明、模型页、桌宠气泡、执行记录步骤名）。Python 侧改了 `skills.py / loop.py`，Godot 侧改了 `pet.gd`。

**验证**：回归 138 项通过（新增标签强制、`/api/chat` 带 skill 的接口用例、三条新技能各一组）；`pet.gd` 过 Godot 4.4.1 语义检查。真实模型用例 28–32（标签锁定、改写、问文件×2、提取成表）：

```
.venv/bin/python tests/live_acceptance.py --tier 8b --only 12,14,21,24,25,28,29,30,31,32
```

**顺带修的**：启动器的健康探测改为看后端每秒写的心跳文件（`data/heartbeat`），HTTP 探测只作兜底且不走系统代理——之前开着 VPN 时探本机会被代理吞掉，启动器误判后端死了而反复重启，这就是"连接中断，正在重连"的真正来源；后端加了事件循环看门狗，卡超过 3 秒会把卡住的代码行写进 `desktop.log`。
