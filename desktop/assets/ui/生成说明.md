# Lulu 桌宠小框

使用内置 image_gen 工具生成；PNG保留真实透明通道，原图未裁切或重绘。框内文案与按钮由程序绘制，随状态更新且可点击。

最终素材：lulu-speech-frame.png。

最终提示词：

Use case: ui-mockup. Generate a production-ready transparent PNG UI frame asset, not a screenshot or mockup. A single wide low rounded speech-card frame for underneath a cute golden-orange capybara desktop pet named Lulu. Aspect ratio approximately 3:1. Warm ivory creamy center, apricot orange soft hand-drawn double outline, tiny rounded capybara ears subtly integrated at top corners, a small orange/tangerine and green leaf tucked against one outer corner, restrained little peach paw accents at bottom corners. Cozy cute polished illustrated game UI, gentle volume, crisp edges, no heavy shadow. Large completely blank plain cream center for live Chinese status text and a row of interactive controls, keep decorations strictly on edges and leave 80% of width usable. NO words, NO letters, NO text, NO character inside card. True transparent alpha everywhere outside this standalone rounded frame; no checkerboard, no background scene. Frame fills canvas closely with a small transparent margin. This is intended as a reusable app texture; use simple clean uncluttered edges and consistent cream-orange palette.
