# Lulu 完整预览版 0.3

当前可运行交付为 **Lulu Preview.app（macOS Apple 芯片）**。双击启动，自动打开独立工作面板和透明桌宠。包含本地 7B 模型、模型运行组件、Python、Node 和 DeepSeek Harness，使用时不需要配置开发环境。

关闭面板会隐藏面板，桌宠继续运行；点击桌宠“打开 Lulu”可重新打开。点击桌宠“退出”关闭本应用启动的后台服务。

面板提供对话、长期记忆、文件、任务、提醒。生成的文件可直接打开；修改前自动备份。运行中可以停止任务，未完成任务保留记录。程序意外退出后重新启动，已保存的记忆和提醒仍在。

用户数据保存在 `Library/Application Support/Lulu`；日志在其中的 `logs/desktop.log`。应用与数据分离，更新应用不覆盖用户数据。

这是完整功能预览，不是已验证所有复杂任务都可靠的正式产品。扫描版 PDF 的 OCR、复杂版式还原尚不支持；文档转换以文本重建为主。提醒需应用运行，退出后下次启动可看到到期提醒。长期记忆删除目前会同时清空旧对话与任务上下文，界面会确认。

**Windows 仍是产品目标。** `build_windows.ps1` 是 Windows 本机构建入口，使用 Windows 的 Python 和依赖构建，可把模型与运行组件放入同一目录。目前尚未生成并验收 Windows 安装包，也未完成 Windows 虚拟机/低配办公实机测试；不能用本次 Mac 结果代替 Windows 性能结论。
