你好，我是 Lulu，一只住在桌面上的小水豚。平时陪你待着，需要帮忙时，打开工作窗口就能翻译、整理文件、写点东西、记事或设提醒。

## 第一次打开

1. 完整解压 ZIP，把整个文件夹放到你想保存的位置。不要在压缩包里直接运行，也不要只移出其中的程序。
2. 双击 **`{installer}`**。首次运行会检查动画包，并提示你选择是否下载本地模型。
3. 桌宠出现后，点旁边的“聊聊天”打开工作窗口。

之后每次双击同一个脚本即可启动。包里已包含全部动画和运行环境，**不需要安装 Python**。

## 让 Lulu 能回答你

默认使用电脑上的 Qwen3 模型。请先安装 [Ollama](https://ollama.com/download)，再运行启动脚本，按提示下载模型：

- 内存 **16GB 及以上**：8B 模型，约 5GB。
- 内存不足 16GB：两个 4B 模型，合计约 5GB。

模型需要另外下载，不包含在这个安装包里。下载完成后的本地推理不需要联网；天气和联网搜索仍需要网络。

如果已有 API 或命令行工具，可以不安装 Ollama、不下载本地模型，先打开 Lulu，在“设置 → 模型”选择 API、Claude 命令行或其他命令行，配置后点“检查连接”。外部服务是否收费取决于你使用的账号或服务。

## 先试一件小事

在输入框上方选一个标签，再输入内容或选择文件：

- **翻译 / 总结 / 改写润色**：贴上文字，选语言、长度或语气。
- **问文件 / 提取成表**：选文件，再写问题或需要的表格列名。
- **按要点写 / 转格式**：提供要点和材料，或选择文件与目标格式。
- **记一下 / 提醒 / 查一下 / 聊聊天**：直接告诉 Lulu 要记什么、何时提醒，或想查、想聊什么。

例如：“30分钟后提醒我喝水”。请核对回复中的时间，并让 Lulu 保持运行；关闭期间错过的提醒会在下次打开时补送。

字太小可以在设置里调大界面。“深度思考”默认关闭，打开后本地模型可能多花一两分钟。

## 文件和数据在哪里

对话、笔记、记忆、提醒和生成的文件保存在：

`{data_dir}`

密钥另存于该目录下的 `data/secrets.json`。默认本地模型在本机处理；使用外部 API 或命令行服务时，请求和相关资料可能发往所选服务，界面会提示。天气、城市定位和联网搜索也会访问网络。

卸载时先退出 Lulu，再删除安装文件夹。数据目录会保留；更新或重装时不要删除它。

## 目前的限制

不支持扫描 PDF 的文字识别，也不能完整保留复杂文档排版。小模型可能出错，重要结果请核对。无密钥联网搜索可能慢或失败。8GB 内存旧电脑是设计目标，尚未完成该配置的真机验收。
