# Lulu {version} · {platform_name} {edition_name}

Lulu 是一只住在桌面右下角的小桌宠，旁边是一个工作窗口：翻译、总结、改写、问文件、提取成表、按要点写、转格式、记一下、提醒、查一下、聊聊天。模型可以是本机的 Qwen3（不联网、不花钱），也可以是你自己的 API、`claude -p` 或别的命令行工具——在工作窗口的“设置”页切换。

## 怎么开始

1. 把整个文件夹放到你想放的地方（别放在压缩包里直接双击）。
2. 双击 **{installer}**。第一次会补齐缺的东西，之后每次双击都是直接启动。
3. 桌宠出现在屏幕右下角，点它旁边的“聊聊天”打开工作窗口。

第一次运行时它会做这些事（都能中途关掉，下次再继续）：

- {frames_line}
- 本地模型：如果电脑上装了 [Ollama](https://ollama.com/download)，会问你要不要下载 Qwen3 模型（16GB 内存以上 8B，约 5GB；以下 4B，约 2.5GB×2）。没装 Ollama 也能打开 Lulu，在“设置”页改用 API 等后端。
- {runtime_line}

## 装在哪里，数据在哪里

程序就在这个文件夹里，删掉文件夹就是卸载。你的对话、笔记、提醒和生成的文件在：{data_dir}。更新程序不影响这些数据。

## 出问题了

启动失败时会弹出 `启动问题.txt`；更详细的在 {data_dir}/logs/desktop.log。把这两个发给开发者就行。

版本：{version}（{build_date}）。校验值见同目录的 .sha256 文件。
